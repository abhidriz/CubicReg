# Cubic Regression - Line of Best Fit

This program finds the line of best fit for any 2D cubic patterned dataset using gradient descent. Its purpose is to demonstrate how machine learning in the sense of how cubic regression model will learn from the points and try to make the best fit possible.

## Important

The repo's commits may seem off from what I actually worked on. I just pushed everything I had from ssh to here

## Requirements
- pandas
- matplotlib

## How to Run
1. Add your CSV dataset into the data/ folder
2. Change the filename in code/cubicreg.py to match your dataset for the dataFrame variable
3. Run: python3 code/cubicreg.py

You can run this in either your IDE's terminal or cmd prompt

## Installation
Make sure you have Python installed, then install the required libraries:

You can get python on its website
You can get matplotlib and pandas by using pip:

- pip install matplotlib (or pip3)
- pip install pandas (or pip3)

## Viewing Output
- Local machine: use plt.show()
- On a server like rlogin: use plt.savefig("output.png")

This is if you are running on IDE
